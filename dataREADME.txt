Data Sources & Reproduction Notes / 数据来源与复现说明
========================================================

This repository does NOT bundle GB-scale raw data because they exceed the GitHub
single-file limit (100 MB). Download the raw datasets below, place them under
data/, then run the corresponding scripts to reproduce the thesis results.
本仓库不直接附带 GB 级原始数据，原因：超过 GitHub 单文件限制（100MB）。
请按以下说明下载原始数据放入 data/ 目录，再运行对应脚本即可复现论文结果。

========================================================
1. BindingDB  (DTI data source #1 / DTI 数据来源之一)
========================================================
Source / 来源: Kaggle public dataset / Kaggle 公开数据集
URL / 地址: https://www.kaggle.com/datasets/rajaryan2315/bindingdb-for-drug-target-interaction
Original database / 原始数据库: BindingDB (UCSD) - https://www.bindingdb.org/rwd/bind/index.jsp

Expected file after download / 下载后应得到的文件:
    bindingdb_highconf_pKd_clean.csv

Dataset schema / 数据结构 (in case the Kaggle link goes offline / 供链接失效时核对):
    A curated and cleaned version of BindingDB, focused on drug-target
    interaction (DTI) prediction tasks. It contains compound SMILES strings,
    protein sequences, and their corresponding binding affinities (pKd values).
    该数据集为 BindingDB 的整理与清洗版本，面向 DTI 预测，含化合物 SMILES
    字符串、蛋白序列及其对应的结合亲和力（pKd 值）。

    Columns / 列名:
      - compound_iso_smiles : compound isomeric SMILES / 化合物同分异构 SMILES
      - target_sequence     : protein / target sequence / 蛋白（靶点）序列
      - affinity            : binding affinity (pKd) / 结合亲和力（pKd 值）

    Cleaning rule / 清洗规则:
      Duplicated & incomplete entries, and compounds missing SMILES or without
      a valid target sequence, have been removed.
      重复条目、不完整条目，以及缺少 SMILES 或无有效序列靶点的化合物已被删除。

Used in: thesis Chapter 3 DTI data construction / 用于论文第 3 章 DTI 数据构建。
Place the file under / 放置目录: data/dti/bindingdb/
Processing scripts / 对应处理脚本:
    - filter_and_standardize_bindingdb_smiles_initial.py
    - extract_bindingdb_uniprot_ids.py
    - annotate_bindingdb_gene_symbol.py

========================================================
2. ChEMBL37  (DTI data source #2 / DTI 数据来源之二)
========================================================
Source / 来源: ChEMBL official REST API (no manual download, fetched online).
ChEMBL 官方 REST API（无需手动下载，脚本在线抓取，可完全复现）。
URL / 地址: https://www.ebi.ac.uk/chembl/

Fetch script / 抓取脚本: fetch_chembl37_by_api.py
Downstream scripts / 后续处理脚本:
    - filter_and_standardize_chembl_smiles_initial.py
    - extract_chembl_uniprot_ids.py
    - annotate_chembl_gene_symbol.py

========================================================
3. DrugBank  (DDI data source / DDI 数据来源)
========================================================
Source / 来源: DrugBank full database XML (drugbank_all_full_database.xml).
DrugBank 官方全量 XML。
URL / 地址: https://go.drugbank.com/releases
Note: requires a registered DrugBank account to download. 需注册账号下载。
Thesis Chapter 4 DDI & target info is stream-parsed from this XML.
论文第 4 章 DDI 与靶点信息来自该 XML 的流式解析。

Place the file under / 放置目录: data/ddi/
Processing script / 对应处理脚本: extract_ddi_and_targets.py

========================================================

无需手动下载，按脚本顺序运行即可重建。

Reproduction order / 复现总顺序
========================================================
DTI : fetch/standardize BindingDB & ChEMBL -> annotate gene symbols
      -> merge_and_normalize -> compute descriptors -> FAISS search & validation

      -> z-score -> pair classification -> batch predict & validate
